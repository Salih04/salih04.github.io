01 Research platform · Stage 2 in progress

FinanceIQ

Research question

Can a leakage-safe T+1 pipeline produce a reliable signal—and can its measurement apparatus prove that it did?

Approach

40+ validated features, walk-forward evaluation, frozen protocols, provenance checks, FastAPI + React + Docker, and an LLM constrained to verified structured data.

Findings

Stage 1 was marked FAILED AS WRITTEN — INFORMATIVE after the positive control missed expected sensitivity. Stage 1b calibration showed roughly .10 undetected, .20 weak, .30 at ~61%, .35 at ~87%, and .40 at ~96%. A theta=0 background association and target-linked missingness exposed apparatus confounding; a fail-open non-finite/degenerate-statistic path was fixed fail-closed without rerunning historical results.

Result

Stage 2 is preregistered on main; its implementation is open in PR #37 after independent review and a clean local 1314/1314 suite. No scientific Stage 2 run or outcome exists yet.

02 Active engineering lead

SAMS

Problem

Agent workflows are difficult to inspect when orchestration, model routing, and human approval live in separate tools.

Approach

Tenant-aware authorization, FastAPI, Temporal, Redis, PostgreSQL, immutable execution-room snapshots, and a resumable WebSocket event protocol; React Three Fiber provides the spatial interface.

Result

A substantially matured in-progress agent platform with tenant isolation, explicit authorization, and resumable event foundations. EVENT-REPLAY-3 frontend correctness work is active; rollout remains off until validation, and real-Redis recovery evidence is still pending. I lead a two-person team, assign bounded tasks, review pull requests and validation evidence, and coordinate acceptance and integration. The repository remains private.

FastAPI Temporal Redis PostgreSQL R3F

03 Applied ML system

Parking Lot Detection

Problem

Parking-space occupancy needs stable per-space classification rather than generic full-frame vehicle detection.

Approach

YOLOv8 classification on cropped parking-space polygons with stream processing, debounce, and occupancy tracking.

Result

A public applied-computer-vision system supporting image, video, webcam, and stream inputs without inventing accuracy claims here.
