01Completed capstone

FinanceIQ

Research question

Can a leakage-safe T+1 pipeline find a reliable signal across BIST-listed companies?

Approach

40+ validated features, walk-forward evaluation, FastAPI + React + Docker, and an LLM constrained to verified structured data.

Result

The expanded 81-ticker training universe still produced weak, unstable walk-forward IC near zero. The negative result is reported, not hidden.

02Advanced prototype

SAMS

Problem

Agent workflows are difficult to inspect when orchestration, model routing, and human approval live in separate tools.

Approach

FastAPI, Temporal, Redis, PostgreSQL, and a React Three Fiber office that renders agents as navigable spatial work.

Result

A serious in-progress orchestration system with config-driven model routing and human-in-the-loop control. Repository remains private.

03Applied ML system

Parking Lot Detection

Problem

Parking-space occupancy needs stable per-space classification rather than generic full-frame vehicle detection.

Approach

YOLOv8 classification on cropped parking-space polygons with stream processing, debounce, and occupancy tracking.

Result

A public applied-computer-vision system supporting image, video, webcam, and stream inputs without inventing accuracy claims here.

04Learning tool

CLI Task Queue

Problem

Personal agentic coding sessions need explicit priority, dependency, and failure rules.

Approach

A Go CLI using a priority heap, dependency checks, skip rules, goroutines, and WaitGroup coordination.

Result

A compact public learning tool for reasoning about queue state and concurrent execution.
