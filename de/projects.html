01Abgeschlossenes Abschlussprojekt

FinanceIQ

Forschungsfrage

Kann eine leckagesichere T+1-Pipeline über BIST-notierte Unternehmen hinweg ein verlässliches Signal finden?

Ansatz

40+ validierte Features, Walk-Forward-Evaluation, FastAPI + React + Docker und ein LLM, das auf verifizierte strukturierte Daten beschränkt ist.

Ergebnis

Das erweiterte Trainingsuniversum mit 81 Tickern lieferte weiterhin einen schwachen, instabilen Walk-Forward-IC nahe null. Das negative Ergebnis wird berichtet, nicht verborgen.

02Fortgeschrittener Prototyp

SAMS

Problem

Agenten-Workflows sind schwer nachvollziehbar, wenn Orchestrierung, Modell-Routing und menschliche Freigabe in getrennten Werkzeugen liegen.

Ansatz

FastAPI, Temporal, Redis, PostgreSQL und ein React-Three-Fiber-Büro, das Agenten als begehbare räumliche Arbeit darstellt.

Ergebnis

Ein ernstzunehmendes, in Arbeit befindliches Orchestrierungssystem mit config-gesteuertem Modell-Routing und Human-in-the-Loop-Kontrolle. Das Repository bleibt privat.

03Angewandtes ML-System

Parkplatz-Belegungserkennung

Problem

Die Belegung von Parkplätzen erfordert eine stabile Klassifikation je Stellplatz statt einer generischen Fahrzeugerkennung im Gesamtbild.

Ansatz

YOLOv8-Klassifikation auf zugeschnittenen Stellplatz-Polygonen mit Stream-Verarbeitung, Debounce und Belegungs-Tracking.

Ergebnis

Ein öffentliches, angewandtes Computer-Vision-System mit Unterstützung für Bild-, Video-, Webcam- und Stream-Eingaben, ohne hier erfundene Genauigkeitsangaben.
