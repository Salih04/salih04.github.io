SAMS: durable, multi-tenant execution for LLM workflows

An agent pipeline (plan → code → review → human approval) runs for minutes or hours. Clients disconnect, operators race, tenants share one event stream, and the execution backend may be down. SAMS is built so each of those produces an explicit outcome instead of a silent wrong one.

  • Python · FastAPI · asyncpg
  • PostgreSQL 16
  • Redis 7 Streams + Lua
  • Temporal

04 · failures

Failure cases, and what happens

Redis restarts without persistence

Epoch rotates; resuming clients get stream_reset, never another stream's entries as their history.

integration/test_redis_stream_epochs.py

An event's room has no resolvable owner

The whole replay is withheld (tenant_resolution_failed) rather than a prefix the client would trust.

integration · unit

Refresh token replayed

The session family is revoked, including the replacement just issued. Two concurrent refreshes from one tab also revoke — a deliberate trade-off.

integration/test_postgres_races.py

Temporal unreachable on the declared tier

503 with a machine-readable code, task FAILED, execution_launch_failed audited. Never run in-process instead.

integration/test_temporal_real_server.py

Worker dies during an approval wait

The decision is recorded while no worker runs; a new worker resumes the workflow and completes the task.

integration/test_temporal_real_server.py

Activity keeps failing

Retried by policy (3 attempts, exponential backoff), then the task is marked FAILED and the workflow fails.

06 · limits

What is not proven

  • unproven
    Not deployed: no production traffic. Not load-tested: no numbers for reconnect storms or throughput.
  • default off
    Resumable delivery is behind a flag that defaults to off; default clients get an at-most-once live tail plus HTTP resync.
  • dev server
    Temporal is verified on a dev server only: no production cluster, no server restart, workflow changes not yet versioned.
  • design
    Tenant isolation is enforced in application queries, not row-level security; roles are account-level.
  • out of scope
    Agent output quality is not evaluated; the infrastructure around the agents is.

The source repository is private. A curated public extract of the reliability layer, with its tests and a hash manifest tying it to the private code, is being prepared.
